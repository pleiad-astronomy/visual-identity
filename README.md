# Pleiad Astronomy: visual identity

The logo of the [Pleiad Astronomy](https://pleiad-astronomy.github.io) group, in every variation we use.

**Logo designed by Ingrid Beloto**, a former member of the group.

The logo is a spiral galaxy drawn as a single line, with stars around it. The full versions add the name *Pleiad* in script, and some add Urania, the muse of astronomy, holding up a star.

*[Em português](#em-português)*

## Which file should I use?

| You need | Use |
| :-- | :-- |
| The logo on a light background (white slides, documents, posters) | `pleiad logo preto (sem azul).png`, or `pleiad logo preto urania (sem azul).png` to include Urania |
| The logo on a dark background | `pleiad logo branco urania (sem azul).png` |
| The logo with its soft blue glow | any file without "(sem azul)" |
| A full image with a starry sky (covers, social media) | the `estrelado` JPGs |
| A small logo (avatar, favicon, app icon) | a `sem nome` file: the name and Urania can't be read below about 64 pixels |

## All variations

The file names are in Portuguese. Each one combines three choices:

- **preto** (black drawing, for light backgrounds) or **branco** (white drawing, for dark backgrounds)
- the full logo with the name, **urania** (with Urania as well), or **sem nome** (without the name: galaxy and stars only)
- a soft blue glow behind the drawing, **sem azul** (without the glow: transparent background), or **estrelado** (a starry sky, as a JPG)

All images are 3832 × 3832 pixels. The PNGs have transparent backgrounds, so the white versions look blank in a viewer with a white background: open them on a dark one.

## Using the logo

These files are the visual identity of the Pleiad group. If you'd like to use them outside Pleiad materials, please get in touch first. When you use the logo, please keep Ingrid's credit with it where there's room for one.

## Em português

Este repositório guarda o logo do grupo [Pleiad Astronomy](https://pleiad-astronomy.github.io) em todas as suas versões. **O logo foi criado por Ingrid Beloto**, ex-integrante do grupo.

Os nomes dos arquivos combinam três escolhas: **preto** ou **branco** (cor do desenho, para fundos claros ou escuros); o logo completo com o nome, **urania** (com a Urânia também) ou **sem nome** (só a galáxia e as estrelas); e o fundo com brilho azul, **sem azul** (fundo transparente) ou **estrelado** (céu estrelado, em JPG).

Para fundos claros, use as versões **preto**; para fundos escuros, as **branco**. Em tamanhos pequenos (avatares, ícones), use as versões **sem nome**: abaixo de uns 64 pixels o nome e a Urânia ficam ilegíveis.

Estes arquivos são a identidade visual do grupo Pleiad. Para usá-los fora dos materiais do grupo, entre em contato antes. Ao usar o logo, mantenha o crédito à Ingrid sempre que houver espaço.
